# RentPro 4.0

ระบบจัดการโกดังให้เช่า: ภาพรวม → บิลหลัก → มิเตอร์ย่อย → ใบแจ้งหนี้ → รับชำระและใบเสร็จ

## ใช้งาน

- หน้าตัวอย่าง: `https://omrjco.github.io/rentpro/?demo=1`
- ข้อมูลตัวอย่างมีโกดัง ผู้เช่า และสัญญาครบ 4 หลัง พร้อมบิล 2 เดือน สถานะจ่ายครบ จ่ายบางส่วน รอชำระ และเกินกำหนด
- ปุ่มด้านบนสลับข้อมูลจริงกับข้อมูลตัวอย่าง ข้อมูลสาธิตไม่ส่งไปคลาวด์
- ภาพบิลและหลักฐานรับชำระรองรับ PNG/JPEG/WebP ไม่เกิน 5 MiB ต่อภาพ
- บิลที่ออกแล้วเก็บสูตร อัตราต้นทุน ผู้เช่า และผู้ให้เช่าเป็นภาพข้อมูล ณ วันที่ออกบิล
- เอกสารสัญญาในรุ่นนี้เป็นสรุปข้อมูลเพื่อการจัดการ ไม่ใช่สัญญาสำหรับลงนาม

## แหล่งข้อมูลและการย้ายรุ่น

ข้อมูลจริงใช้ฐานข้อมูล IndexedDB `RentProData` และคีย์ `rentpro_v2` เดิม ข้อมูลสาธิตแยกไว้ที่ `rentpro_demo_v4` สำรองข้อมูลเดิมก่อนเปิดรุ่น 4 ที่ `rentpro_backup_before_v4` ไม่ใส่ตัวอย่างทับข้อมูลจริง

Firebase ใช้คอลเลกชัน `rentpro` เดิม แยกบันทึกเป็นราย entity และใช้ `v3_manifest` ป้องกันแก้พร้อมกัน ภาพใหญ่แยกเป็นส่วน ก่อนเชื่อมกับข้อมูลทางการเงิน ข้อมูล legacy `main` อ่านเพื่อย้ายแต่ไม่เขียนทับ การเชื่อมต่อและกฎสิทธิของฐานข้อมูลจริงต้องตรวจด้วย config ของเจ้าของโครงการ ไม่มี key จริงในซอร์ส

## ซอร์ส

- `v4-app.js`: หน้าจอและขั้นตอนงาน
- `v4-model.js`: สร้างบิล รับเงิน และยอดคงเหลือ
- `v4-demo.js`: ชุดข้อมูลสมมติ
- `v4.css`: รูปแบบคอม มือถือ และเอกสาร A4
- `upgrade-core.js`: สูตรคำนวณ การย้ายข้อมูลเดิม และตรวจความขัดแย้ง
- `cloud-records.js`: ซิงค์แบบแยกรายการและภาพแนบ
- `local-store.js`: ฐานข้อมูลในเบราว์เซอร์

## สร้างและตรวจ

ใช้ Python 3 และ Node.js 20 ขึ้นไป ไม่มี dependency เพิ่มเติม

```sh
python3 build-v4.py
node test-core.cjs
node test-v4.cjs
node test-cloud.cjs
node test-v4-print.cjs
```

`build-v4.py` รวมโมดูลเป็น `index.html` สำหรับ GitHub Pages และ `dist/index.html` สำหรับตรวจภายใน แก้ซอร์สแล้วสร้าง `index.html` ใหม่ก่อนเผยแพร่ ห้ามใส่ข้อมูลจริงหรือไฟล์สำรองของผู้เช่าใน repository

## ข้อกำหนดการคิดต้นทุน

ต้นทุนเดือนปัจจุบัน = ค่าการใช้ + ค่าบริการ + Ft + VAT ตามบิล − ส่วนลด ไม่รวมยอดค้างเก่า ค่าปรับ และเงินประกัน หารด้วยหน่วยในบิลหลัก คิดผู้เช่าตามมิเตอร์ย่อย ส่วนต่าง หน่วยของห้องว่าง และเศษปัดทศนิยมเป็นต้นทุนเจ้าของ หากสัญญาไม่ครอบคลุมรอบมิเตอร์หรือเปลี่ยนผู้เช่าในรอบ จะหยุดให้ออกบิลเพื่อให้แยกหน่วยเข้า–ออกก่อน
